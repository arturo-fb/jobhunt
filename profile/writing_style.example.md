# Writing style (optional)

Copy this file to `profile/writing_style.md` and describe how you write, so cover
letters sound like you rather than like a template. The fastest way to build it:
give your AI assistant three or four things you have written (essays, emails,
papers) and ask it to describe your voice under these headings. Then edit it.

## Overall voice
- e.g. warm and direct; first person; prefers short sentences / long multi-clause sentences

## Phrases you actually use
- e.g. "I would like to highlight…", "a clear example of this is…"

## Things to avoid
- e.g. buzzwords, exclamation marks, overly formal openings

## How you open and close
- e.g. opens with the scope and the main point; closes with a concrete next step
